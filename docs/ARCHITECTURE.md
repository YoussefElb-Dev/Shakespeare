# Architecture

`QuoteSettings` and `Quote` are immutable domain values with defensive local decoding. `AppController` owns settings, the current generation, and the local collections. It serializes persistence writes, bounds history to 200 entries, reports storage failures, and uses a request generation counter so cancelled/late responses cannot replace newer work. Favorites are stored independently from history, so clearing history preserves favorites.

`QuoteService` separates live HTTPS generation from the explicitly labelled offline preview collection. A failed live request never silently falls back to a sample. Options are captured when a request starts; settings changes do not rewrite a pending quote’s metadata. Copy uses the platform clipboard; sharing uses `share_plus`, including an iPad share-anchor rectangle.

The shared UI uses one stateful flow: home → categories → customize → generating → quote. Native Android back navigation and iOS back controls return through the flow. Modal selectors use the same dark surfaces on both platforms. Arabic/Egyptian Arabic and Hebrew activate localized, RTL interfaces. Urdu quote content is also RTL; other interfaces remain English. The saved quote’s language controls its text direction and bundled font.

`LiquidOrb` owns a shader instance and repaints within a `RepaintBoundary`. Its clock integrates smoothed generation intensity, accelerating the folds without discontinuous phase jumps. Breathing, traveling folds, changing reflections, and a deforming silhouette animate at rest; generation adds contraction, faster flow and glow. Pointer pressure and displacement settle smoothly. Animation suspends in the background, outside TickerMode, or with Reduce Motion. The Canvas fallback follows the same phases.

Generating and finished quotes share one scene key and one `QuoteBubble`, preserving the orb's State and clock. An independent finite reveal drives the shader's bloom/ripple and brings text out of the center through expansion, lifting, opacity and blur. The text subtree is cached during animation; selection is enabled when it settles. Reduce Motion skips the reveal. The UI has its own generation sequence guard so a cancelled response cannot interrupt a newer pending request. Every editable field explicitly dismisses focus on an outside tap, including touch devices; modal selectors account for keyboard insets.

`AsechkaService` talks directly to the existing first-party Asechka session and publishing endpoints. Its site code is used only for login, while a signed session is stored using the platform's secure storage. Authenticated requests refuse redirects. The app persists a quote's operation ID before sending and only records success after a JSON response confirms the same ID and `posted: true`. The separate Asechka backend verifies the session, restricts this route to adding quotes, and commits to the canonical collection with concurrency checks and idempotency. Website and native Asechka feed refreshes see that same collection. Neither the Gemini gateway nor mobile build settings receive Asechka's GitHub publishing token.

Fragment work stays in a bounded region; the app makes no unmeasured frame-rate guarantee. Shader loading failures use a procedural Canvas fallback.

The iOS bridge registers a native UIKit glass view and a capability channel. iOS 26+ supplies `UIGlassEffect`; Flutter handles controls, text, semantics, and taps. Native material samples the native composition available to UIKit, which can differ from the Flutter shader scene. Android and earlier iOS use a clipped Flutter blur/gradient treatment. The shared app does not switch to Android Material navigation or category styling.

The gateway is an anonymous HTTPS API. It enforces input options rather than accepting client-supplied models or system prompts, reserves usage atomically through a Durable Object SQL transaction, and calls Gemini generateContent with structured JSON output. The Google AI Studio key stays in a Worker secret. Missing secrets and quota failures fail closed. Google free-tier quota exhaustion returns a retryable 429 without a paid fallback. User inspiration is supplied as data, separate from writing instructions. Script checks catch obvious Arabic/Hebrew output-language mistakes; they do not replace native-language quality review.

CI runs format checks, static analysis, and unit/widget tests before compiling native binaries. Signing credentials are installed only on trusted non-PR events. Signed builds require a live backend configuration. Android can always compile a debug-key preview release-mode APK. iOS without Apple credentials validates the simulator and compiles an ARM64 iPhoneOS release app, packaged as an unsigned device IPA for re-signing by the user’s sideloader. The packager verifies both SDK metadata and the Mach-O iOS device platform, rejecting simulator binaries. Distribution credentials enable a signed exported IPA. Versioned releases are populated only from successful signed outputs.
